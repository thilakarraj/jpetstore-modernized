# JPetStore Security Documents --- Modular Monolith

Revised security baseline aligned to a FastAPI modular monolith,
Account/Catalog/Cart/Order modules, one MySQL database/schema, JWT
validation inside FastAPI, and backend-first delivery.

Included: - SECURITY_ASSESSMENT.md - SECURITY_DECISIONS.md -
SECURITY_REMEDIATION_PLAN.md - SECURITY_TEST_CASES.md -
SECURITY_RISK_REGISTER.md

Legacy finding IDs and test IDs are retained. These documents are
proposed for review and approval; they do not claim that implementation
or runtime security tests have passed.
